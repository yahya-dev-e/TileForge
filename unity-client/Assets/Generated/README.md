# TileForge AI - Generated Assets Directory

This directory stores output assets generated directly from the TileForge LevelGenWindow inside Unity:
- `<TileName>_Diffuse.png` (Imported as 2D Sprite, Repeat Wrap Mode)
- `<TileName>_Normal.png` (Imported as Normal Map)
- `<TileName>_Mat.mat` (Universal Render Pipeline 2D Lit Material)
- `<TileName>_Prefab.prefab` (2D Platform Tile with PolygonCollider2D)
